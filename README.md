# 📚 eLearning Company

This is a landing page for **eLearning Company**, designed to showcase various eLearning services and packages.

🔗 **Live Demo:** [eLearning Company](https://alinaa2501.github.io/eLearning-Company/)

---

## 🚀 Tech Stack
- **HTML, SCSS, JavaScript**
- **Node.js v22.12.0**
- **npm v11.0.0**

## 🛠️ Installation & Setup
To run this project locally, follow these steps:

```sh
git clone https://github.com/alinaa2501/eLearning-Company.git
cd eLearning-Company
npm install
npm run build:sass
```

Note: The project already includes all necessary files, so running npm run build:sass is optional unless you need to recompile styles manually.
